Support Ticket Management System – Version 1

📖 Overview

This project is a simplified Support Ticket Management System. It allows users and admins to manage support tickets efficiently — from creation to resolution — while keeping the interface clean and easy to navigate.

Version 1 focuses only on core ticket operations.

💡 Problem Statement

Organizations often struggle with scattered support requests across emails, chats, or spreadsheets. There is no clear way to track ticket ownership, status, or resolution time.

This leads to delays and poor communication between users and administrators.

🌟 Product Vision

This system is designed as a simple, structured, and user‑friendly platform that centralizes all support requests. The goal is to make ticket handling transparent, organized, and efficient.

⚙️ How the Product Solves the Problem

  • Centralized Dashboard showing open and closed tickets
  • Ticket Queue with clear priority and status
  • Quick ticket creation via "Raise New Ticket"
  • Editable ticket details with comments
  • Admin control for ownership

🚀 Application Workflow

Login

Users log in to access the system.

  • Admins can access all features
  • Users cannot access Some features and pages

Dashboard

  • Displays ticket statistics
  • Shows recent tickets
  • Auto-generated Ticket ID
  • Default Owner = Admin

Tickets Queue

  • Lists all tickets
  • Columns: ID, Title, Priority, Status
  • View button opens details
  • New Ticket button available

Raise New Ticket

  • Fields: Title, Priority, Status, Description
  • Submit & Cancel buttons available

Ticket Details

  • View full ticket info
  • Edit: Title, Priority, Status
  • Comment section included
  • Back navigation available

Users (Admin Only)

  • List of all users
  • Admin can Delete Users

Logout

Ends session and redirects to login.
